# 使用教程
1. npm安装,一般AI对话`/`会自动加载出这个skill
2. 在对话里把skill.md文件发给你的chatAI，它也能读取到markdown文件

# 下载方式

1. 通过**npm**安装：
```bash
npm install baowenfeng
```

2. **CLI**：
```bash
npx baowenfeng
```
