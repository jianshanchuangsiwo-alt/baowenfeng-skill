# 使用教程

 **npm安装之后，`/`会自动加载出这个skill**
 - (好像有一点问题，有些ai不会加载出来)
    
**在对话里把skill.md文件发给你的chatAI，它也能读取到markdown文件**
 - (最稳妥的方式，用起来比较麻烦，每次对话都要发一遍这个文件)
    
**直接把`skill.md`放到AI对应的路径文件下，没有的可以新建一个`skills文件`**
 - (最实用的方法，基本没有问题，但小白可能比较难受......)
