# 使用教程
- npm安装,一般AI对话`/`会自动加载出这个skill
- 在对话里把skill.md文件发给你的chatAI，它也能读取到markdown文件

# 下载

- 通过 npm 安装：
```bash
npm install baowenfeng
```

- CLI：
```bash
npx baowenfeng
```
